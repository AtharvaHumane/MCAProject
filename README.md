# MCAProject

Full-stack salon booking app with a React client and an Express/MongoDB server.

## Project Structure

- `client` - React frontend
- `server` - Express backend API

## Prerequisites

- Node.js
- MongoDB running locally at `mongodb://127.0.0.1:27017/salon`

## Run Locally

1. Start the backend:

```bash
cd server
npm install
npm start
```

2. Start the frontend in a second terminal:

```bash
cd client
npm install
npm start
```
